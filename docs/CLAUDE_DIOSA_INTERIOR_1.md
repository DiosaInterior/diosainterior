## 1. IDENTIDAD DE MARCA

### 1.1 Qué es Diosa Interior

La primera guía de colorimetría construida específicamente para piel latina. No es una app de belleza genérica — es autoridad científica con alma editorial. La referencia visual es **Vogue México & Latinoamérica**: lujo oscuro, tipografía serif dominante, espacio negativo generoso, precisión editorial.

### 1.2 La Tensión Visual de la Marca

Diosa Interior opera con una tensión permanente entre:
- **Oscuridad y luz** — fondo borgoña profundo + destellos dorados cálidos
- **Ciencia y alma** — datos de colorimetría + identidad latina
- **Sofisticación y autenticidad** — estética de lujo + piel real sin retoque

### 1.3 Principio Rector de Diseño

> *"El mejor diseño es aquel en el que nada puede ser eliminado sin que el conjunto pierda sentido."*

Si un elemento puede eliminarse sin perder información o impacto → eliminarlo.

### 1.4 Test de Identidad (usar antes de publicar)

Antes de publicar cualquier pieza, hacerse esta pregunta: **"¿Podría esta pieza ser de L'Oréal, Maybelline, o cualquier app de belleza genérica?"**
- Si la respuesta es **sí** → no es suficientemente Diosa Interior. Rediseñar.
- Si la respuesta es **no** → bien encaminado.

Segunda pregunta: **"¿Podría esta pieza salir en Vogue México?"**
- Si la respuesta es **sí** → aprobado.

### 2.2 Reglas de Color — ABSOLUTAS

**✅ SIEMPRE:**
- Fondo principal: Vino Profundo `#1A0808`
- Texto principal: Marfil `#FDF0E8`
- Acento dominante: Terra Diosa `#C4724A`
- Proporción: **70% oscuro / 20% marfil / 10% terra**
- Máximo 3 colores de la paleta en una sola pieza

**❌ NUNCA:**
- Fondo blanco puro `#FFFFFF`
- Fondo negro puro `#000000`
- Azules, verdes, morados como color dominante
- Degradados de colores fríos
- Más de 3 colores de la paleta en una pieza
- Colores saturados sobre colores saturados

### 2.3 El Gradiente Maestro

```css
background: radial-gradient(ellipse at center, #3E1818 0%, #1A0808 70%);
```

Solo este gradiente. Ningún otro. Crea profundidad sin ruido.

### 2.4 Uso del Oro

El oro (`#C4962A` o `#B8860B`) es el color del metal para tonos cálidos. Úsarlo únicamente como:
- Línea decorativa ultra fina (1px)
- Símbolo ✦ en ocasiones específicas
- **Nunca** como fondo ni como texto largo

3. Negrita en Cormorant — la itálica es el peso
4. Texto subrayado
5. Sombras duras en texto
6. Más de 3 colores tipográficos en una pieza
7. Raleway en minúsculas para labels
8. DM Mono para headlines o texto emocional

10. Más de 35 caracteres por línea en headline
11. Texto centrado si son más de 3 líneas de body copy (usar izquierda)
12. Cambiar posición del texto entre escenas del mismo Reel
13. Omitir el ornamento de apertura

## 5. COMPOSICIÓN Y LAYOUTS

### 5.1 Principio Vogue de Composición

La imagen y la tipografía forman una sola composición orgánica — el texto no se "pone sobre" la imagen como un cartel; ambos se dan sentido mutuamente.

Regla del espacio negativo: **mínimo 20% del frame** debe ser espacio vacío. Las marcas de lujo dejan respirar; las de fast fashion llenan cada pixel.

### 5.2 Los 5 Layouts Maestros

**Layout 1 — EDITORIAL COVER** (Posts hero, slide 1 de carrusel)
- Fotografía ocupa 60–70% del frame
- Texto en el tercio inferior
- Eyebrow en Terra, headline en Cormorant Italic

**Layout 2 — TEXTO DOMINANTE** (Carrusel educativo, hooks de texto)
- Texto ocupa 80% del frame
- Espacio negativo superior
- Separador decorativo con ✦

**Layout 3 — SPLIT COMPOSITION** (Comparativas, antes/después)
- Frame dividido en dos mitades iguales
- Cada mitad con su propia composición

**Layout 4 — DATO HERO** (Estadísticas, porcentajes impactantes)
- El número ocupa 60%+ del frame en DM Mono grande
- Contexto en Cormorant Italic debajo
- Minimalismo extremo

**Layout 5 — GRID DE BENEFICIOS** (Slide de cierre CTA)
```css
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 28px 24px;
}
.item {
  display: flex;
  flex-direction: column;
  align-items: center;
  gap: 10px;
  padding: 24px;
  border: 0.5px solid rgba(196, 114, 74, 0.18);
}
```

### 5.3 Márgenes Mínimos

- Feed 1080×1080: mínimo **60px** todos los lados
- Reel/Story 1080×1920: ver Sección 6 (Safe Zone)
- Padding lateral sobre safe zone: mínimo **90px**

## 6. SAFE ZONE INSTAGRAM

### 6.1 Dimensiones Críticas para Reels 1080×1920

```
Canvas total:    1080 × 1920 px

ZONA PELIGROSA — NUNCA poner texto aquí:
  Arriba:     y = 0 → 120px      (UI: botones, cámara)
  Abajo:      y = 1640 → 1920px  (Caption, likes, audio — 280px)
  Derecha:    x = 990 → 1080px   (Botones de interacción — 90px)
  Izquierda:  x = 0 → 50px       (Buffer de seguridad)

ZONA SEGURA:
  x: 50px → 990px    (ancho útil: 940px)
  y: 120px → 1640px  (alto útil: 1520px)
```

### 6.2 Implementación CSS

```css
* { margin: 0; padding: 0; box-sizing: border-box; }
body {
  width: 1080px;
  height: 1920px;
  background: transparent;
  overflow: hidden;
}

.safe {
  position: absolute;
  left: 50px;
  top: 820px; /* ajustar: 820–1050px según cantidad de contenido */
  width: 940px;
  display: flex;
  flex-direction: column;
  align-items: center;
  padding: 0 90px;
}
```

### 6.3 Regla de Anclaje Vertical (CRÍTICA)

**Todo el texto en todas las escenas de un mismo Reel debe tener el mismo `top` de anclaje vertical.** El ojo de la espectadora aprende en la escena 1 dónde está el texto — en las siguientes ya lo espera ahí. Cambiar de posición entre escenas genera drop-off. Videos con posición inconsistente sufren 22% menos completion rate.

### 6.4 Exportación con Playwright (Python)

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page(viewport={"width": 1080, "height": 1920})
    page.goto(f"file://{html_path}", wait_until="networkidle")
    page.wait_for_timeout(3200)  # crítico: esperar Google Fonts
    page.screenshot(
        path=png_path,
        full_page=False,
        omit_background=True  # fondo transparente para overlay
    )
    browser.close()
```

### 6.5 Verificación de Safe Zone (Python / Pillow)

```python
from PIL import Image
img = Image.open(png_path)
r, g, b, a = img.split()
region_peligrosa = a.crop((0, 1640, 1080, 1920))
pixels = list(region_peligrosa.getdata())
fuera = sum(1 for p in pixels if p > 10)
assert fuera == 0, f"⚠️ {fuera} píxeles fuera de safe zone"
print("✓ Safe zone verificada")
```

## 8. ALGORITMO DE INSTAGRAM 2026

### 8.1 Los 3 Factores Críticos (confirmados por Adam Mosseri)

| Señal | Peso | Definición |
|-------|------|-----------|
| **Watch Time** | 🔴 Crítico | Los primeros 1.7 segundos determinan si se quedan o se van |

**POSITIVO:**

- Guardar (save)
- Compartir por DM — la señal más fuerte
- Comentar con más de 5 palabras
- Ver un Reel más de una vez (rewatch)

**NEGATIVO:**
- Scroll rápido (bounce en primeros 2 segundos)
- Tap "No me interesa"
- Ocultar publicaciones
- Reportar contenido
- Dejar de seguir después de ver

## 10. SISTEMA DE CARRUSELES

### 10.1 Especificaciones Técnicas

- **Slides ideales:** 7–10 (menos de 4 no tiene ventaja algorítmica)
- **Máximo:** 20 slides
- **Dimensiones:** 1080×1080 px (cuadrado) o 1080×1350 px (portrait)
- **Padding:** 80px todos los lados

### 10.2 El Arco Emocional (9 slides — estructura estándar)

```
Slide 1 — HOOK: Tensión / afirmación contraria (impacto inmediato, máx 8 palabras)
Slide 2 — VALIDACIÓN: "Y no es tu culpa" — el sistema falla a la piel latina
Slide 3 — PROBLEMA: Qué pasa cuando usas los colores equivocados
Slide 4 — DATO: El gap de 180k tonos, fototipos IV–VI, realidad LATAM
Slide 5 — GIRO: Existe una solución específica para ti
Slide 6 — CÓMO: Cómo funciona nuestra IA (sin tecnicismos)
Slide 7 — PRUEBA: Resultado visual / ejemplo paleta correcta vs incorrecta
Slide 8 — CIERRE: Frases aspiracionales de marca
Slide 9 — CTA: Nunca de presión — "Descubre tu paleta" / "¿Cuál es tu tono?"
```

**REGLA CRÍTICA DE CARRUSEL:**
- Slide 1: hook que no puede ignorarse
- Slides 2–3: suficientemente fuertes por sí solos (segunda oportunidad algorítmica)
- Último slide: guardable — incluir resumen, checklist o paleta

### 10.3 Reglas de Carrusel

✅ Caption que invite a deslizar: "Desliza para ver tu paleta →"
✅ Logo en la misma posición en todos los slides
✅ Consistencia visual total entre slides
❌ No empezar con slide de presentación o logo
❌ No hacer carruseles de menos de 4 slides

### 10.4 Temas de Carruseles Aprobados

1. "Los colores que te dicen que uses probablemente te apagan"
2. "Tu fototipo IV no existe en la mayoría de apps de colorimetría"
3. "Así funciona nuestra IA con 180,000 tonos de piel latinos"
4. "Antes y después: paleta incorrecta vs paleta Diosa"
5. "Por qué el color de temporada no es para ti"

## 12. OVERLAYS DE REEL (PNG TRANSPARENTE)

### 12.1 Estructura de Overlay — Orden Fijo de Arriba a Abajo

```
1. Ornamento (línea + diamond)        margin-bottom: 28–40px
2. Eyebrow (Raleway uppercase)        margin-bottom: 28–36px
3. Headline (Cormorant Italic)        [el corazón de la pieza]
4. Separador ✦                        margin-top: 42–44px / margin-bottom: 34–40px
5. Texto de soporte (si aplica)       margin-bottom: 36–52px
6. URL / CTA final (DM Mono)
```

**Sin texto de soporte:** omitir separador y paso 5. Headline va directo al final.

### 12.2 Escena de Cierre / CTA (la más elaborada)

```
1. Ornamento
2. Eyebrow con contexto completo
3. Headline CTA (110–112px)
4. Separador ✦
5. Grid 2×2 de beneficios (si aplica)
6. URL en DM Mono
```

### 12.3 Checklist de Verificación de Overlay

**TIPOGRAFÍA:**
- [ ] ¿Cormorant está en itálica? (`font-style: italic`)
- [ ] ¿Raleway en uppercase? (`text-transform: uppercase`)
- [ ] ¿DM Mono solo para datos técnicos?
- [ ] ¿Máximo 3 niveles tipográficos?
- [ ] ¿Textos de soporte mínimo 16px?
- [ ] ¿Headline mínimo 88px?

**COLORES:**
- [ ] ¿Headline en `#FDF0E8`?
- [ ] ¿Eyebrow en `#C4724A` o variante con opacidad?
- [ ] ¿Sin colores inventados fuera de la paleta?

**SAFE ZONE:**
- [ ] ¿Contenedor en `left:50px / top:[820–1050]px / width:940px`?
- [ ] ¿Ningún píxel visible debajo de `y=1640`? (verificar con Pillow)
- [ ] ¿Padding lateral mínimo 90px?

**CONSISTENCIA:**
- [ ] ¿Todas las escenas tienen el mismo `top` de anclaje?
- [ ] ¿El ornamento abre todas las escenas?
- [ ] ¿El separador ✦ aparece donde corresponde?

**EXPORTACIÓN:**
- [ ] ¿PNG con `omit_background=True`?
- [ ] ¿Modo RGBA verificado?
- [ ] ¿Viewport exacto 1080×1920?
- [ ] ¿`wait_for_timeout(3200)` para Google Fonts?

## 13. CAPTIONS Y VOZ DE MARCA

### 13.1 La Voz de Diosa Interior

**Es:** íntima-experta, declarativa, latinamente orgullosa
**No es:** coach motivacional, vendedora, tutorial genérico, gurú de wellness

**Referencia Vogue:** Vogue escribe *"Moda Consciente"*, *"Estilo Responsable"* — frases que declaran, no que venden. Diosa Interior escribe *"Tu paleta"*, *"Tu piel"*, *"Tu análisis"* — nunca frases de venta directa.

### 13.2 Fórmula de Caption

```
[Hook — primeras 2 líneas ANTES del "más"] ← Lo más importante

[Desarrollo — 3–5 líneas que amplían el hook]

[Dato específico LATAM]

[Cierre aspiracional — voz Diosa Interior]

[CTA único y claro]

[Keywords naturales en el texto, no forzadas]

#hashtag1 #hashtag2 #hashtag3 (máx 5)
```

### 13.3 Arquitectura del Hook

**Fórmula:** [Afirmación que contradice lo que creen] + [dato específico LATAM]

**Hooks aprobados:**
- "Los colores que llevas años usando probablemente fueron diseñados para piel europea"
- "Tu paleta de estación fue calibrada con undertones rosados que son estadísticamente raros en fototipos IV–VI"
- "El 78% de las apps de colorimetría usan referencias que no representan tu piel"
- "Llevas años usando el color favorito de otra persona"
- "Ninguna de las apps que usaste fue entrenada con piel latina"

### 13.4 Keywords Prioritarias (para SEO en captions)

- colorimetría latina
- análisis de color piel morena
- paleta de colores personal
- fototipo IV V VI
- colores para piel cálida
- undertone dorado oliva

### 13.5 Hashtags Aprobados (usar 3–5, no más)

`#colorimetría` `#análisisdecolor` `#pielmexicana` `#piellatinaesbeautiful` `#paleta` `#colorimetríalatina` `#pielmorenapreciosa` `#undertone`

### 13.6 Palabras y Frases PROHIBIDAS

- "Transforma tu look"
- "Descubre tu mejor versión"
- "Tips para verte increíble"
- "En este post te voy a enseñar"
- "No te pierdas esto"
- "Increíble", "Sorprendente", "Impresionante" (elogios genéricos)
- "En el mundo de hoy"
- "Como nunca antes"
- Cualquier frase que suene a gurú motivacional
- Anglicismos innecesarios cuando existe equivalente en español natural

### 13.7 Red-Team Antes de Publicar

1. ¿Esto podría venir de cualquier cuenta de belleza genérica? → Reescribir
2. ¿Hay alguna frase que suene a texto de IA? → Humanizar
3. ¿El hook es contrario, específico, impredecible? → Aprobado
4. ¿La voz es íntima-experta, no coach-motivacional? → Aprobado

## 18. GLOSARIO

| Término | Definición |
|---------|-----------|
| **Watch Time** | Tiempo total que los usuarios pasan con tu contenido |
| **Sends per Reach** | Veces que el contenido fue enviado por DM ÷ alcance total |
| **Completion Rate** | % de usuarios que vieron el Reel hasta el final |
| **Engagement Rate** | (Saves + Shares + Comments) ÷ Reach |
| **Safe Zone** | Área de Instagram libre de UI que cubre el contenido |
| **Terra Diosa** | Color acento principal — `#C4724A` |
| **Vino Profundo** | Fondo estándar de la marca — `#1A0808` |
| **Marfil** | Color de texto principal — `#FDF0E8` |
| **Ornamento de apertura** | Línea + diamond de Terra Diosa que abre toda composición |
| **Separador ✦** | Elemento decorativo entre headline y texto de soporte |
| **Dark Radial** | El gradiente estándar de fondo: `radial-gradient(ellipse at center, #3E1818 0%, #1A0808 70%)` |
| **Eyebrow** | Texto pequeño uppercase sobre el headline — establece contexto |
| **Protagonista** | La mujer generada por IA que aparece en el Reel de Transformación |
| **Sin Saber** | Frame "antes" — protagonista con colores incorrectos |
| **Siendo Ella** | Frame "después" — protagonista con prescripción colorimétrica correcta |
| **Mystic 2.5 Fluid** | Modelo de imagen Freepik — mejor para fotografía realista de personas |
| **MiniMax Hailuo 2.3** | Modelo de video Freepik para animaciones |
| **Cross Dissolve** | Transición de fundido entre los dos videos en DaVinci |
| **Hook** | El texto de apertura — lo primero que lee la espectadora |
| **Frame 0** | El primer fotograma del video — donde debe aparecer el texto |
| **Trial Reel** | Feature de IG que muestra el Reel solo a no-seguidores para testear |
| **Fototipo IV–VI** | Clasificación de Fitzpatrick para pieles morenas y oscuras — el foco de Diosa Interior |
| **Undertone** | Matiz subyacente de la piel (dorado, rosado, oliva, neutro) |
| **Estación colorimétrica** | Categoría de análisis de color (Otoño Cálido, Primavera, etc.) |
